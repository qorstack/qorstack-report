§01 — HOW IT WORKS

      
Zero layout code.
The people who know how the document should look keep editing it in Word. Your code only sends data.

    

    

      
01
Upload a template
Mark the blanks in a .docx or .xlsx — text, table rows, images, QR codes.
invoice.docx

      
02
Send JSON
One POST with your API key — from your app, a cron job or an AI agent.
POST /render

      
03
Get the file
A download link to the finished file, kept in history for audit.
invoice.pdf
